# Proof Point Register

Every item below separates verification status from publication status. Planning examples, suggested future proof categories, and placeholder requests are not treated as proof.

## Status Vocabulary

Verification Status:

- `Verified`
- `Partially Verified`
- `Unverified`
- `Rejected`

Publication Status:

- `Publishable`
- `Client Approval Required`
- `Consent Required`
- `Internal Only`
- `Not Usable`

An item is public-ready only when:

```text
Verification Status = Verified
Publication Status = Publishable
```
