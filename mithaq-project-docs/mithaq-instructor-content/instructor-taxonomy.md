# Instructor Taxonomy

## Approved Role Formatting

Use factual, concise role labels only.

Pattern:

```text
[Current Role]
[Current Role], [Organization]
[Professional Context] Mentor
```

Examples are structural only, not assigned:

- Legal Research Mentor
- Legal Writing Instructor
- Professional Readiness Mentor
- Litigation Practice Mentor
- Corporate Law Instructor

Do not use:

- Leading Expert
- Renowned Lawyer
- Top Mentor
- نخبة الخبراء
- خبير بارز
- أفضل مدرب

## Arabic Name Rules

- Use the instructor's approved Arabic name if supplied.
- If only an English name is supplied, request approved Arabic spelling or transliteration.
- Do not guess Arabic name spelling from English.
- Preserve professional honorifics only if approved.
- Avoid long honorific chains in public cards.

## Organization Naming Rules

- Use official organization names exactly as approved.
- Do not translate firm/company names unless an official Arabic name exists.
- Do not imply current employment if only past affiliation is supplied.
- If organization publication is not approved, use a safer professional-context phrase only after client approval.

## Quote Versus Paraphrase Rules

- Direct quotes require exact approved text and attribution.
- Do not invent quotations.
- Do not place quotation marks around paraphrased authority statements.
- If no statement exists, use `[CLIENT INPUT REQUIRED: APPROVED AUTHORITY STATEMENT]`.

## Experience-Year Rules

- Use years of experience only when explicitly confirmed.
- Do not calculate experience from incomplete dates.
- Do not round up.
- Do not infer seniority from age, title, photograph, or tone.
- If years are unconfirmed, hide the field.

## Claims Classification

Every profile statement must be tagged before publication:

- `Verified`
- `Client Confirmation Required`
- `Internal Only`

Do not publish `Client Confirmation Required` or `Internal Only` statements as facts.
