# Source Notes

## Creation Method

The P4.06 texture library was generated procedurally in the local workspace using the bundled Python runtime and Pillow.

Generation method:

- Random seed: `4606`
- Canvas size: `1024 x 1024` for base/subtle textures
- Preview size: `512 x 512`
- Output format: WebP for optimized CSS/static/editorial use
- Contact sheet: PNG and HTML visual previews
- Source imagery: none

## Family Procedures

| Family | Procedural Method |
| --- | --- |
| Dark Wood | Layered dark brown bands, sinusoidal grain, elliptical knots, subtle noise, vignette. |
| Aged Parchment | Warm ivory base, fiber lines, subtle age marks, softened edge treatment. |
| Gold Foil | Muted brass-gold base, diagonal brushed bands, soft foil variation, restrained grain. |
| Dark Leather | Dark folio base, fine grain, pore marks, low-contrast arcs, softened noise. |

## KTX2 Status

No local `toktx` or `basisu` encoder was available in the workspace runtime. KTX2 conversion is intentionally marked pending and must be done later with a verified encoder.
