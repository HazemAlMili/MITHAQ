## Retained English Terms

- `WebGL` - retained in handoff because it is a technical implementation term.
- `RTL` - retained in handoff because it is the standard implementation acronym.
- `[CLIENT INPUT REQUIRED: ...]` placeholders - preserved in English for consistency with project dependency tracking.

## Usage Principles

- Use `عملي` where it clarifies training practicality, not as decoration in every scene.
- Avoid `متميز`, `شامل`, `احترافي`, and `حقيقي` unless a future approved source requires them.
- Avoid `نخبة الخبراء` and similar authority inflation until instructor profiles are approved.
- Avoid wording that implies Mithaq provides legal advice rather than training.
